Common mistakes

  1. Local means correct. The recorded small model confidently gets 17 wrong. Verify important facts independently.
  2. Loopback means no network. Model downloads use network. Cloud-disabled is an application setting; native components and the OS are not packet-audited.
  3. Stop means restored. Model/log/result files remain. Native runner children and OS caches can outlive the server. Do not delete an existing .ollama folder to undo a lesson.

Frequently asked questions

What do I need before starting?

Python 3.10+ and an independently trusted Ollama binary supporting OLLAMA_NO_CLOUD=1. Windows official docs offer a standalone CLI archive as an alternative to an installer. Obtain it in a new folder and check its provenance; this lesson does not run an installer or upgrade an existing setup.

What replaces the path placeholder?

The full path to your trusted executable, quoted if it has spaces. FULL_PATH_TO_TRUSTED_OLLAMA_BINARY is a teaching placeholder, not a real executable. The recorder substituted its verified standalone runtime path.

Why does the wrapper refuse to start?

An occupied 127.0.0.1:11439 port, existing output folder, unsafe path or missing cloud-disabled confirmation is a stop condition. Use another new lesson folder, not deletion of existing data or another person's process.

Is it private?

Only fictional prompts are used here. Requests target loopback with environmental proxies disabled; the server is configured cloud-disabled and its log is checked. This is not a network audit, authentication or isolation guarantee. Download still uses network.

Is it free?

No payment or subscription is requested by this wrapper. Download/storage/compute/data costs remain. Code is MIT, Ollama runtime is separately MIT, and Llama 3.2 has its own Community License and Acceptable Use Policy, not unrestricted use. Review those terms before downloading.

Does stopping clean everything?

No. Files are retained and native runner children can remain. The recording observed locked runtime DLLs after server stop. No automatic uninstall, deletion or restoration is promised.

Why did 17 fail?

The recorded 1B model answered wrongly. 17 has no divisor among 2, 3, 4, which covers every possible divisor up to its square root, so it is prime. One correct capital answer does not establish reliability.
